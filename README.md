# 笼中物 · CagedBird

一个纯手工程序化生成的 Three.js 小场景：一棵树上挂着黑色铁丝鸟笼，笼中斜卡着一把**可以自由涂装的活动扳手**，一键可替换为**幺鸡麻将牌**；树下是帐篷与篝火的营地，日月星辰循环流转。物理、音效、贴图、模型全部程序化生成，零外部素材。

**双击 [`dist/index.html`](dist/index.html) 即可离线游玩**（0.63 MB 单文件，无任何外部请求）。

## 功能

### 场景与氛围
- **铁丝鸟笼**：穹顶肋条、16 根立柱、三道横箍、底盘与门扣，经链条悬挂在树枝上，受扰动呈真实单摆运动
- **扳手**：挤出成型的活动扳手（圆尾挂环、C 形头环、滚花蜗杆），斜卡在笼子中间；**幺鸡麻将牌**：手绘绿雀红睛贴图 + 圆角象牙牌身，一键切换、弹入动画
- **营地**：A 形帐篷（帐门正对篝火）+ 篝火（石圈、柴堆、90 粒火舌、烟雾、闪烁点光带投影、地面光斑）
- **日月变迁**：昼 → 黄昏 → 夜三态连续过渡——太阳绕场公转，天空渐变与雾色同步流转，日月盘升落，420 颗星入夜渐显，月光冷色补照（面板可开关）
- **云朵**：低多边形积云缓慢东漂
- **音效**：WebAudio 实时合成——金属撞击（非谐分音 + 噪声瞬态，随冲量变调）、风声环境、随机鸟鸣短语（面板可开关音效与鸟叫）

### 物理（cannon-es）
- 笼子是**动力学 compound 刚体**（底盘 / 栏杆 / 封闭内壁 / 穹顶 / 顶盖，102 个碰撞盒），经点约束挂在树枝锚点：摆动来自真实重力，自转由角速度目标平滑驱动
- **全封闭碰撞壳**：连续内壁圆筒 + 加厚防隧穿设计，物品在物理上无法离开笼子
- **点击笼子**施加冲量：笼身晃动、笼内物品被真实带动抛掷；物品碰撞、摩擦、休眠全部交给解算器
- **切换物品 = 换碰撞箱**：未选中者从物理世界摘除，摘除时存笼局部位姿、重挂原地恢复
- **碰撞框调试**：面板一键显示所有碰撞盒线框（笼子青 / 扳手橙 / 幺鸡品红），隔笼可见

### 涂装
- **渐变涂装**：头 / 中 / 尾三段取色器实时重涂（顶点色），附参考 / 金属 / 落日 / 墨玉 / 随机预设
- **笔刷涂色**：在扳手上按住拖动即可涂色，径向渐变笔刷，涂色时视角锁定、笼子自转暂停

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖拽 / 滚轮 / 右键 | 环绕旋转 / 缩放 / 平移 |
| 点击笼子或笼内物品 | 物理冲量晃动，物品被抛起 |
| 笔刷模式下按住扳手拖动 | 涂色（不转视角） |
| 面板标题点击 | 折叠 / 展开面板 |

面板开关：自动环绕 · 笼子慢转 · 音效 · 碰撞框 · 鸟叫 · 日月变迁。

## 快速开始

```bash
# 离线游玩：直接双击
dist/index.html

# 开发（本地服务器 + 源码版）
python -m http.server 8137     # → http://127.0.0.1:8137

# 物理回归测试（4 阶段：自转浸泡 / 点击风暴 / 切换重置 / 30s 折腾）
npm test

# 重新构建单文件产物
npm run build
```

无构建依赖即可运行源码版（three 与 cannon-es 已本地化到 `vendor/`）；构建需要 `npm install`。

## 项目结构

```
index.html          源码版页面：场景搭建、涂装、音效、UI（模块脚本）
physics.js          笼中物理（cannon-es）：与页面和测试共用同一套搭建代码
physics.test.mjs    物理回归测试（node 直跑，无需浏览器）
build.mjs           esbuild 单文件打包（输出 dist/index.html）
vendor/             本地化的 three 0.160 与 cannon-es 0.20
dist/index.html     构建产物：单文件、离线可玩
```

## 技术要点

- **坐标系一致性**：渲染网格与刚体使用同一变换源（物品组直接挂 scene，位姿由 `syncVisuals` 一步写入）——"渲染和碰撞盒不贴合"这类问题的根源就是双重变换
- **运动学 teleport 的坑**：不要每帧把视觉位姿"钉"给物理体再差分速度——位姿跳变（如自转暂停恢复）会产生巨大角速度把接触物发射出去。笼子改为真动力学 + 点约束后自然消失
- **广相选择**：4 刚体场景用 `NaiveBroadphase`，朴素配对零漏检，且不受反复 `addBody/removeBody` 影响（SAP 在频繁挂载切换下会漏配碰撞对）
- **音频零素材**：全部 WebAudio 合成（振荡器、噪声缓冲、滤波器、LFO），主音量总线统一开关
